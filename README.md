#  Dakheel – Car Marketplace Platform

A full-scale car marketplace platform designed to provide users with a seamless experience for browsing, comparing, and booking cars.

##  Live Demo

- **Website:** https://dakheelcars.com/
- **Admin Dashboard:** https://panel.dakheelcars.com/dashboard

##  Key Features

- Dynamic car listings and detailed vehicle pages.
- Advanced search and filtering.
- Favorites system to save preferred cars.
- Car comparison feature.
- Car booking requests and booking status tracking.
- Dedicated Admin Dashboard.
- Vehicle, brand, category, and booking management.
- Responsive user interface.
- Arabic and English language support.
- Dark and Light mode.

##  Technologies Used

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Redux Toolkit
- REST APIs
